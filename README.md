# Santa Cruz

List SQLite databases, create new ones and run queries.
Made to simplify the management of SQLite databases for LLM tools.
Bring an easy integration via function calling to sqlite databases.

## Features

- [x] List SQLite databases
- [x] Add SQLite database
- [x] Remove SQLite database
- [x] Edit SQLite database
- [x] List tables
- [x] Run queries
- [ ] Create new SQLite database
- [ ] API


## Development

```bash
nix-shell
```

Database
```bash
sqlc generate
```
